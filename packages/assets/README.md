# @topclans/looped-loader-assets

The 32 pre-transcoded H.264 clips and the `manifest.json` that describes them,
for the `looped-loader` packages. Measured contents: **32 clips, 4 049 965
bytes** in total; the largest clip is `u3dob97sw2421` at 430 452 bytes — the
set's single `budget-exceeded` exception, recorded with its reason in
[`qc-report.md`](./qc-report.md) alongside every other QC finding.

Every file here is generated by `tools/transcode` and verified against
`checksums.json` on every build of this package — never hand-edit anything in
it.

See the root [README](../../README.md) for both hosting recipes (self-hosted
next to your app, or a CDN/baseUrl setup) and for the licensing boundary: this
package's media is not covered by the code's MIT grant — see `NOTICE`.
