`@topclans/looped-loader-assets` ships the 32 pre-transcoded H.264 clips and the
`manifest.json` that describes them for the `looped-loader` packages.

Every file here is generated by `tools/transcode` and verified against
`checksums.json` — never hand-edit anything in this package.

See the root README for both hosting recipes (self-hosted next to your app, or a
CDN/baseUrl setup).
