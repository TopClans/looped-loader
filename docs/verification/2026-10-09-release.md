**One anomaly, recorded rather than smoothed over.** The very first load of that app, before the
instrumentation was added, sat with `readyState: 4`, `paused: true` and `data-state: loading` for
at least four seconds; a manual `video.play()` from the page started it and the state moved to
`playing` immediately. Two subsequent instrumented loads, and the earlier E3.1 browser pass over
32 loaders, all played. The cause was not established, and the most likely area — the template's
`autoplay` attribute racing the core's explicit `play()` on a freshly mounted element — is a
hypothesis, not a finding. If it recurs, this paragraph is the starting point.

## Follow-ups

1. **The `0.0.1` placeholders.** Each package carries a deprecated `0.0.1` under the `placeholder`
   dist-tag, published to reserve the name so that `npm trust` could be configured at all. It is
   deprecated (`npm view …@0.0.1 deprecated` returns the message) and never carries `latest`.
2. **`npm trust` needs an existing package.** The design-time question is answered: with a working
   authenticated session, `POST …/-/package/@topclans%2flooped-loader-core/trust` answered
   `404 Not Found` while the package did not exist, and succeeded once it did. See D-33.
3. **Writes on this account need proof of presence.** `npm deprecate` from a granular token
   answered `EOTP`, and the trusted-publisher configuration opened the browser challenge
   (`https://www.npmjs.com/auth/cli/…`). The release itself needed no interactive approval —
   OIDC supplied the proof.
4. **The release workflow does not create the GitHub Release.** It has `contents: read`; creating
   a release needs `contents: write`. It was created by hand this time. Adding the step is a
   deliberate widening of the workflow's token permissions and belongs to the owner, so it is
   documented in `docs/release.md` rather than changed here.
5. **Four Dependabot pull requests are open** (`actions/checkout` 4→7, `setup-node` 4→6,
   `pnpm/action-setup` 4→6, `upload-artifact` 4→6). The release run carries a Node 20
   deprecation warning until they land.
6. **The npm token created for this release must be revoked**, and the `~/.npmrc` entry removed:
   `npm config delete //registry.npmjs.org/:_authToken`.
